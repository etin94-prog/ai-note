## 사용자 점검 (2026-10-10, Sprint 4 후)

체험 모드·가상 데이터로 브라우저 창에서 사용자처럼 직접 눌러 보며 저장된 값까지 확인했다 (Playwright 대신).

| 영역 | 확인한 흐름 | 결과 |
|---|---|---|
| 학원·수강 | 학원 추가(계좌이체·납부 담당) → 수강(월·수 19–21, 30만, 5일) → 시간표 반영 | 일치 |
| 일정 | 추가(이 일정만 알림) → 준비물 체크 → 전체 수정(시간 변경) → 삭제 | 버그 2건 수정 후 일치 |
| 반복 일정 | 매주 토 → 한 회차 취소 → "이후 모두" 시간 변경(원본 끊고 새 일정) | 일치 |
| 학원 수업 회차 | 휴강 → 보강 추가 → 휴강 되돌리기 → 이번만 시간 변경 → 결석 | 일치 |
| 학원비 | 자동 청구 3건 → 완납 → 부분납부 → 실행 취소 → 정정(취소) → 감액 → 완납 → 환불 요청·초과 거부 → 수령 6만+4만(초과 거부) → 종결 | 버그 수정 후 일치 |
| 청구·지출 | 특강 청구 추가 → 금액 수정 → 청구 취소·되돌리기 → 필터별 합계 → 기타 지출 추가·삭제 | 일치 |
| 알림 | 40분 뒤 일정 → 종 배지·홈 배너·알림함 → 모두 읽음 → 알림 설정(끄기·시점·학원비 D-n) | 일치 |
| 관리자 | 백업 → 초기화(확인 단어) → 복원, 엑셀 내보내기·가져오기, 화면 13개 렌더 | 이상 없음 |

발견·수정
1. 일정 시작 시각·날짜를 바꾸면 준비물 체크·휴강 기록이 옛 회차에 남아 사라짐 → 수정 시 회차 기록을 새 회차로 옮김(겹치면 합침), 삭제 시 함께 삭제
2. 시간 바꾼 뒤 회차 화면이 "찾을 수 없음" → 같은 일정의 새 회차로 열기
3. 환불 요청·감액·수령 금액 상한 없음(낸 금액보다 큰 환불이 저장됨) → 상한 검사·안내
4. 자녀·담당 필터를 걸어도 "이달 실제 지출"은 전체 기준 → 필터 반영
5. 취소된 청구에 "남은 n만" 표시 → "취소된 청구 (합계에서 빠짐)"
6. 지출·일정·장소·방학 삭제가 한 번에 실행 → "지울까요?" 확인
7. 보강 기본 시각이 16–17시 → 원래 수업 시각
8. 계좌이체 학원도 납부 수단 기본값이 카드 → 학원 납부 방법을 따름
9. 알림 배너가 "1시간 뒤"로 고정 → 지금 기준 남은 시간
10. 화면에 개발 용어(Sprint) 노출, 아이콘 버튼·일정 줄·+ 버튼 읽기 이름 없음 → 정리
